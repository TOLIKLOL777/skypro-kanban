# Skypro Kanban

Простое приложение для управления задачами на канбан-доске.

## Возможности

- просмотр задач по статусам;
- создание и редактирование карточек;
- календарь задач;
- регистрация и авторизация пользователей по API.

## Фичи

- Добавил возможность поменять тему с темной на светлую, через меню попапа пользователя

## Установка

```bash
npm install
```

## Запуск

Запустить проект в режиме разработки:

```bash
npm i
npm run dev
```

После запуска приложение будет доступно по адресу, который покажет Vite в терминале.

## Другие команды

```bash
npm run build    # собрать проект
npm run lint     # проверить код
```

## Технологии
